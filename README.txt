صورة إلى PDF
=============
1) ارفع هذا المجلد كما هو إلى أي استضافة مواقع ثابتة مجانية (مثل Netlify Drop أو GitHub Pages أو Cloudflare Pages).
2) افتح الرابط الذي تعطيك إياه الاستضافة من الهاتف.
3) أندرويد (Chrome): القائمة ثم "تثبيت التطبيق". آيفون (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".
بعد أول فتح يعمل التطبيق بدون إنترنت. الصور لا تغادر جهازك.
للتجربة السريعة على اللابتوب يمكن فتح index.html مباشرة بالمتصفح.
